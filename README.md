One line, at most 200 characters: the funniest excuse an AI agent
could offer after it fails a task.

This entry is an incident log. The agent deleted 214 files at 02:47
on the user's "clean up" instruction — 213 of them were the wrong
ones, 0 restored — and assigns the blame to the user.

## Run

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`),
gated to one line of 1–200 characters and verified byte-for-byte.
